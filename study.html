Exam technique

How to answer

Name the idea, connect it to the numbers or code you were given, then say what it means for the model.

Part 1Multiple choice

  1. Find the knob being asked about: C, gamma, degree, kernel, scaling, n_components, or which method (PCA, LDA, t-SNE).
  2. Recall its direction: small C = wide margin; large gamma = wiggly boundary; PCA = variance; LDA = class separation.
  3. For a table, compare CV scores, not training scores, and treat gaps smaller than one standard deviation as a tie.
  4. Distrust absolute words: "always more accurate", "the most flexible kernel is best", "t-SNE distances are exact".

Part 2Short answer

  1. Define the idea in one sentence ("Support vectors are the training points closest to the boundary").
  2. Explain why or how ("They define the margin, so other points do not move the boundary").
  3. Use the numbers if there is an output ("C = 30 used 13 support vectors, C = 0.03 used 72").
  4. Conclude or recommend ("so choose C with cross-validation, then test once").

Example. "Compare PCA and LDA." PCA is unsupervised: it ignores the labels and keeps the directions of maximum variance, so it suits compression and visualization. LDA is supervised: it uses the labels to maximize class separation and gives at most C − 1 components, so it suits preprocessing for classification. High variance does not guarantee separation: on the penguins, PCA (2) scored 0.872 but LDA (2) scored 0.981.

CodeReading code and outputs

  • Code: say what each step does in order (scale → reduce → model), what each parameter controls, and what would go wrong without it.
  • Outputs: quote the number, compare (train vs CV, model vs model), explain why, and choose.
  • In a pipeline, a parameter is named step__parameter: svc__C is the C of the step called svc.

Module 7

Support vector machines

An SVM draws the boundary with the widest margin between classes. Only the closest points, the support vectors, decide where it goes. C trades margin width for errors, kernels allow curved boundaries, and features must be scaled.

7.1Margin and support vectors

  • Margin: the distance from the boundary to the nearest training points of each class. A wide margin is less sensitive to small changes, so it generalizes better.
  • Support vectors: the points on or inside the margin. They fix the boundary; points far away have no influence, so removing them changes nothing.
  • With two features the boundary is a line; with more it is a hyperplane.

7.2Hard vs soft margin, and C

Hard marginNo point may be inside the margin or on the wrong side. Only works when the classes separate perfectly, and one outlier can ruin it. Rarely used.
Soft marginAllows some margin violations and errors. Used in practice. C sets how much a violation costs.
Small CLarge C
MarginWiderNarrower
ViolationsToleratedHeavily penalized
RegularizationStrongerWeaker
RiskUnderfittingOverfitting
  • Large C fits the training data more closely and keeps fewer support vectors (13 vs 72), because the margin is narrower.
  • Judge it by the CV score, not the training score. No value of C is best for every dataset: choose it with cross-validation.

7.3Feature scaling (always)

SVMs work with distances. Body mass is in grams (thousands) while bills are in millimetres, so without scaling body mass decides everything. StandardScaler gives every feature mean 0 and SD 1. Trees and forests do not need this; SVMs do.

  • Scaling lifts the RBF model from 0.594 to 0.968: the raw units were distorting the distances.
  • The scaler sits inside the pipeline, so each CV training fold learns its own mean and SD and nothing leaks from the validation fold. Fit on training data, then transform the test data.

7.4Kernels and the kernel trick

The kernel trick computes the similarity between points as if they had been mapped to a higher-dimensional space, without creating those features. The SVM can then draw curved boundaries cheaply.

KernelFormulaBoundaryUse it for
Linearxᵢ · xⱼStraight (a linear SVM)Linearly separable or high-dimensional data (text). Fast; a good baseline.
Polynomial(xᵢ · xⱼ + c)ᵈCurved, feature interactionsModerately nonlinear data. Higher degree d = more complex.
Gaussian RBFexp(−γ‖xᵢ − xⱼ‖²)Very flexibleComplex nonlinear data; often the best. Tune C and γ.
Sigmoidtanh(β xᵢ · xⱼ + θ)Like a neural-network activationRarely: sensitive to settings, usually worse than RBF.

Rule of thumb. Start with a linear kernel for linearly separable or high-dimensional data and an RBF kernel for nonlinear problems. There is no universally best kernel: compare them with cross-validation.

  • RBF and linear differ by 0.009, less than one SD: a tie. The most flexible kernel is not automatically the best.

7.5Tuning C, gamma and degree

HyperparameterSmall valueLarge value
C (all kernels)Wide margin, strong regularization → may underfitNarrow margin, fits training data → may overfit
γ gamma (RBF)Each point reaches far → smooth boundaryEach point reaches only nearby → wiggly boundary → may overfit
degree (polynomial)Simple curveHigh-order curve, slower → may overfit
  • C = 0.1 with γ = 0.01 underfits: both scores are low.
  • C = 10 with γ = 5 has the best training score (0.992) but not the best CV score: a sign of overfitting.
  • C and γ interact, so tune them together with GridSearchCV.

7.6SVMs in scikit-learn: the full workflow

  • stratify=y keeps the species proportions in both sets; the locked test set is used once, after tuning.
  • svc__C: the C of the pipeline step named svc.
  • Balanced accuracy averages each class's recall, so the small class (68 Chinstrap) counts as much as the large ones.
  • Result: best = linear, C = 10 (CV 0.985, RBF 0.981: a tie). Locked test: 1.000 on 76 penguins, good but not proof of perfection.
  • Multiclass: SVC uses one-versus-one. Three species → three pairwise classifiers (Adelie–Chinstrap, Adelie–Gentoo, Chinstrap–Gentoo).
  • Cascade lab: SVC(..., probability=True) enables predict_proba, needed for ROC-AUC. Models were compared on accuracy, precision, recall, F1 and ROC-AUC, plus confusion matrices and ROC curves.

7.7Support vector regression (SVR)

SVR predicts a number. It fits a tube of width ε around the prediction: errors inside the tube cost nothing, and only points outside it shape the model (C sets their penalty). This makes it less sensitive to small noise.

  • For MAE, lower is better: RBF SVR misses by about 280 g on average. SVR does not always beat linear regression; it depends on the data.

7.8Strengths and limits

StrengthsLimitations
Effective in high-dimensional spaces (text, images, genomics)Sensitive to feature scaling
Good generalization from the maximum marginNeeds tuning of C, γ and degree
Strong on small and medium datasetsSlow on very large datasets
Linear or nonlinear through kernelsHard to interpret, especially with RBF

Check yourself

What does an SVM maximize, and which points decide the boundary?

The margin between the classes. The support vectors, the points on or inside the margin, decide it.

Small C or large C: which gives a wider margin, and what is the risk?

Small C: wider margin and stronger regularization, with a risk of underfitting. Large C narrows the margin and risks overfitting.

Why did the raw-units RBF score only 0.594?

RBF uses distances and body mass in grams dominated them. Scaling (StandardScaler in the pipeline) raised it to 0.968.

What does the kernel trick do?

It computes similarities as if the data were mapped to a higher-dimensional space, so the SVM can draw nonlinear boundaries without creating the new features.

What does a large gamma do in an RBF SVM?

It makes each point's influence very local, giving a complex, wiggly boundary that may overfit.

How does SVC handle three classes?

One-versus-one: one binary classifier for each pair of classes, three for three species.

Module 8

Dimensionality reduction

Too many features make data sparse, slow and easy to overfit. PCA keeps the directions of most variance (no labels), LDA keeps the directions that separate the classes (labels, at most C − 1), and t-SNE draws pictures of local neighbourhoods.

8.1The curse of dimensionality

SparsityThe feature space grows so fast that the observations spread thin, and patterns are hard to find.
Distances stop helpingDistances between points become similar, so k-NN and clustering lose power.
CostMore computation, memory and training time; models need more data.
OverfittingModels learn noise from irrelevant features and generalize worse.

Demo. With random points in 2, 10, 100 and 784 dimensions, the average distance grows but the relative spread (SD ÷ mean) shrinks: everyone becomes about equally far from everyone. MNIST has 784 pixel features per image.

8.2Why reduce, and selection vs extraction

Benefits: faster training, lower storage, less noise, easier visualization (2D/3D), less overfitting. Cost: some information is lost, so accuracy can drop.

Feature selectionFeature extraction
What it doesKeeps a subset of the original featuresCreates new features by combining the originals
MeaningFeatures keep their meaningNew features are harder to interpret
ExamplesLasso setting coefficients to 0PCA, LDA

8.3PCA: principal component analysis

  • Unsupervised: never looks at the labels.
  • PC1 = direction of maximum variance; PC2 = most remaining variance, orthogonal to PC1; and so on. Each component is a linear combination of all the features.
  • Explained variance ratio = the share of total variance each component keeps. 72% + 18% = 90% kept by two components.
  • Standardize first: PCA follows variance, and big-unit features would dominate.
  • Two components keep only 17% of the variance, so the 2-D PCA plot of the digits overlaps a lot.
  • 150 components keep 95% of the variance of 784 pixels, and the reconstructed digits stay recognizable: compression with little loss.
  • Limitations: assumes linear structure, components are hard to interpret, and maximum variance is not always the direction that separates the classes.

8.4How many components?

  1. Scree plot elbow: stop where the bars flatten; after it, extra components add little.
  2. 95% rule: keep enough components for about 95% of the variance (n_components=0.95). For the penguins, 3 components keep 97%.
  3. Check with the model: compare cross-validated accuracy, because high variance ≠ good predictions.
  • PC1 grows with flipper length, body mass and bill length: a body size axis. PC2 is mostly bill depth and length: bill shape.
  • PCA with all 4 components only rotates the axes: same result as the original features.

8.5LDA: linear discriminant analysis

  • Supervised: uses the class labels.
  • Finds directions that put class centres far apart while keeping each class tight (between-class ÷ within-class scatter).
  • At most C − 1 components, where C is the number of classes, no matter how many features.
  • Assumes roughly linear relationships and classes that are approximately normal with similar covariance. Shrinkage makes it more stable when features are strongly correlated.
Dataset (class demos)ClassesMax LDA components
Breast cancer (malignant / benign)21
Penguins (3 species)32 (LD1 carries 88% of the separation, LD2 12%)
MNIST (digits 0–9)109

Careful. LDA's ratio measures class separation; PCA's measures total variance. The two percentages are not comparable.

8.6PCA vs LDA

PCALDA
Learning typeUnsupervisedSupervised
MaximizesTotal varianceClass separation
Max componentsUp to the number of featuresC − 1
Typical useCompression, visualization, explorationPreprocessing for classification
Main cautionHigh variance may not separate classesNeeds labels; linear, normal-ish classes
  • PCA (2) kept 88% of the penguin variance yet lost the Adelie–Chinstrap difference: that variance was mostly body size.
  • With the same number of dimensions, LDA wins because it uses the labels. High variance ≠ class separation.

8.7t-SNE: for pictures only

  • Nonlinear; turns distances into neighbourhood probabilities and keeps local neighbourhoods: close points stay close, so clusters appear.
  • Used for visualization in 2D/3D (images, text, genomics, customer segments).
  • Distances between clusters are not meaningful; results depend on perplexity, initialization and the random seed.
  • Slow, and it does not naturally transform new data, so it is not used before a classifier.
PCAt-SNE
TypeLinearNonlinear
PreservesMaximum variance, global structureLocal neighbourhoods
SpeedFastComputationally expensive
New dataCan transform new dataDoes not generalize to new data
Used forPreprocessing and predictionExploratory visualization

8.8Reduction inside a pipeline, and what the results show

  • Order: scale → reduce → model. Inside the pipeline the reducer is refitted on each training fold, so nothing leaks (critical for LDA, which uses labels).
  • GridSearchCV can swap the reducer like a hyperparameter. Best: LDA (2) + RBF SVM, 0.988, a tie with the original features (0.985) but with 2 inputs instead of 4.
  • PCA kept the accuracy with a fifth of the features: good compression.
  • Two LDA components are great for a plot but throw away too much to separate ten digits. Accuracy depends on the goal: compression, classification or visualization.

Check yourself

Name two problems caused by the curse of dimensionality.

Sparse data, distances that become similar (bad for k-NN and clustering), higher computation, and more overfitting.

Is PCA feature selection or feature extraction?

Extraction: it creates new features (components) by combining the original ones.

Why standardize before PCA?

PCA follows variance, so features in large units would dominate the components.

A dataset has 4 classes. How many LDA components at most?

3 (C − 1), whatever the number of features.

Why can PCA with 88% of the variance classify worse than LDA?

PCA ignores the labels; the high-variance directions (penguin body size) did not separate Adelie from Chinstrap. LDA keeps the separating directions.

Why is t-SNE not used before a classifier?

It cannot transform new data, it is slow and setting-sensitive, and only local structure is meaningful. It is for visualization.

Which method or setting?

Common traps

Most wrong options sound confident. Prefer careful answers: "tie within one SD", "choose by CV", "depends on the data".

WrongRight
"Small C gives a narrow margin"Small C = wide margin, more regularization
"Large gamma gives a smoother boundary"Large gamma = more local, wiggly boundary
"Every training point shapes the SVM"Only the support vectors do
"Trees need scaling, SVMs don't"The opposite: SVMs need scaling, trees don't
"The most flexible kernel is the best"Compare kernels with cross-validation
"Pick C with the test set"Tune with CV on development data; test once
"PCA uses the labels"PCA is unsupervised; LDA uses labels

The day before

Last-minute review

If you can explain these eight lines, you are ready.

  1. SVM = widest margin; support vectors (closest points) define the boundary.
  2. Soft margin: small C = wide margin (may underfit); large C = narrow margin (may overfit).
  3. Always scale for SVM and PCA, inside the pipeline (no leakage).
  4. Kernel trick = curved boundaries without building features. Linear for separable/high-dimensional, RBF for nonlinear; large γ = wiggly.
  5. Tune with GridSearchCV (svc__C), test once; treat gaps under one SD as ties.
  6. PCA: unsupervised, max variance, orthogonal components, 95% rule or scree elbow.
  7. LDA: supervised, max class separation, at most C − 1 components.
  8. t-SNE: local neighbourhoods, visualization only. High variance ≠ class separation.
